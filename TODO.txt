--- Crash recovery and path locks ----------------------------------------------------------------

[ ] Frontend: after a server restart a run that was running is status "running" with
    paused=true and an activity line "The server restarted..."; POST /runs/{id}/resume carries it
    on (the step that was running starts again), POST /runs/{id}/stop ends it. A run that was
    waiting for its command still shows its open question; answering it and resuming continues.
    POST /api/runs answers 409 when a path (or a folder around or inside it) is held by another
    running run; the lock is released when that run is done, failed or stopped.

[ ] Known limits of recovery: it reloads the last saved level (a step in flight is redone, so its
    LLM calls repeat unless cached); confirmed-suggestion jobs and the run-vault ideas of the lost
    step are not rewound (a rerun can add a duplicate idea); path locks are per server process
    (several uvicorn workers would not share them).
